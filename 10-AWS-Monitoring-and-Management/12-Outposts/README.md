## AWS Outposts

AWS Outposts is a fully managed service that extends AWS infrastructure, services, and APIs to **on-premises** data centers or co-location facilities.

- AWS delivers and installs physical rack hardware at your site.
- Run AWS services locally (EC2, EBS, S3, RDS, EKS, etc.) with the same AWS APIs and tools.
- Connects back to an AWS region via a reliable network link for management and access to regional services.
- Use case: Low-latency requirements, data residency/compliance, or workloads that must stay on-premises while connecting to AWS.
