## AWS Trusted Advisor

AWS Trusted Advisor inspects your AWS environment and provides real-time recommendations across five categories to follow AWS best practices.

**Five Check Categories:**
- **Cost Optimization**: Identify unused or underutilized resources (e.g., idle EC2, unattached EBS volumes).
- **Performance**: Improve throughput and service limits (e.g., high-utilization EC2 instances).
- **Security**: Identify security gaps (e.g., S3 buckets open to public, MFA not enabled on root).
- **Fault Tolerance**: Improve resilience (e.g., RDS without Multi-AZ, EBS without snapshots).
- **Service Limits**: Warn when you're approaching AWS service quotas.

**Plans:**
- **Basic / Developer**: Access to ~7 core checks (security & service limits only).
- **Business / Enterprise Support**: Full access to all checks + CloudWatch integration + programmatic access via API.
