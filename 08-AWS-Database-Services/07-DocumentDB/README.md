## Amazon DocumentDB

Amazon DocumentDB is a fully managed **document database** compatible with **MongoDB** — stores, queries, and indexes JSON-like documents.

**Key Concepts:**
- MongoDB-compatible APIs — migrate existing MongoDB apps with minimal changes.
- Storage auto-scales up to 64 TB in 10 GB increments.
- High availability: 6 copies across 3 AZs, up to 15 read replicas.
- Automated backups and point-in-time recovery.

**Use cases:** Content management, catalogs, user profiles, any app using MongoDB or JSON documents.
