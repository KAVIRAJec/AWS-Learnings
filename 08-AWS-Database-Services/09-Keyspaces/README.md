## Amazon Keyspaces

Amazon Keyspaces is a fully managed, serverless **Apache Cassandra-compatible** database service.

**Key Concepts:**
- Uses **Cassandra Query Language (CQL)** — migrate Cassandra workloads with minimal code changes.
- Serverless — automatically scales tables up/down based on traffic.
- Data replicated 3x across multiple AZs.
- Supports on-demand and provisioned capacity modes.
- Encryption at rest (KMS) and in transit (TLS) by default.

**Use cases:** IoT data, time series, mobile backends, high-write/high-scale apps previously using Cassandra.
