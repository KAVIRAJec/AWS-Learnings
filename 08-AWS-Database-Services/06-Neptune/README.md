## Amazon Neptune

Amazon Neptune is a fully managed **graph database** service — optimized for storing and querying highly connected data.

**Key Concepts:**
- Supports two graph models: **Property Graph** (via Gremlin) and **RDF** (via SPARQL).
- High availability: 6 copies across 3 AZs, up to 15 read replicas, automatic failover.
- Supports point-in-time recovery and continuous backup to S3.

**Use cases:** Social networks, knowledge graphs, fraud detection, recommendation engines, network topology.
