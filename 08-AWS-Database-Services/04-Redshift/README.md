## Amazon Redshift

Amazon Redshift is a fully managed **petabyte-scale data warehouse** for OLAP (Online Analytical Processing) and complex queries.

- See detailed notes in [Data Analytics → Redshift](../../13-Data-Analytics-Services/03-Redshift/README.md).

**Quick reference:**
- Columnar storage + MPP architecture for fast analytical queries.
- **Redshift Spectrum**: Query data directly in S3 without loading into Redshift.
- **Redshift Serverless**: Auto-scales without managing clusters.
- Integrates with Glue, Athena, QuickSight, and BI tools.
