## Amazon Timestream

Amazon Timestream is a fully managed, serverless **time series database** — optimized for storing and analyzing time-stamped data at scale.

**Key Concepts:**
- Automatically scales to store and process trillions of events per day.
- Built-in time series functions for smoothing, approximation, and interpolation.
- **Storage tiers**: Recent data in memory, historical data on magnetic storage — automatically tiered.
- Integrates with **Kinesis, IoT Core, Prometheus, Grafana, and QuickSight**.

**Use cases:** IoT sensor data, application metrics, operational monitoring, DevOps telemetry.
