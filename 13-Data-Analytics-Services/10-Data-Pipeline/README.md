## Amazon Data Pipeline

Amazon Data Pipeline is a web service for **scheduling and automating data movement and transformation** between AWS compute and storage services.

- Define data-driven workflows — move data between S3, RDS, DynamoDB, Redshift, and EMR on a schedule.
- Handles retries, failure notifications, and dependency tracking.
- **Note**: Data Pipeline is a legacy service — AWS recommends **AWS Glue** or **Step Functions** for new workloads.
