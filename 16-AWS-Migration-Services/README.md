## AWS Migration Services

AWS provides a set of services to help plan, execute, and track migrations of on-premises workloads to AWS.

---

## Services

| # | Service | Description |
|---|---------|-------------|
| 01 | [Application Discovery Service](./01-Application-Discovery-Service/README.md) | Discover and collect data about on-premises servers before migration |
| 02 | [Application Migration Service (MGN)](./02-Application-Migration-Service/README.md) | Lift-and-shift servers from on-premises or other clouds to AWS |
