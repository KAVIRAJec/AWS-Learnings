## AWS Artifact

AWS Artifact is a **self-service portal** for on-demand access to AWS compliance documentation and agreements — no need to contact AWS support.

**Two main components:**

**1. Artifact Reports**
- Download AWS security and compliance documents — audit reports, certifications, and attestations generated by third-party auditors.
- Examples: SOC 1/2/3 reports, ISO 27001/27017/27018 certificates, PCI DSS compliance packages, FedRAMP authorizations, HIPAA documentation.
- Use these reports to provide evidence to your own auditors or regulators that the AWS infrastructure you use meets compliance requirements.

**2. Artifact Agreements**
- Review and accept legal agreements between your company and AWS — e.g., **Business Associate Agreement (BAA)** for HIPAA, **GDPR Data Processing Addendum (DPA)**.
- Can be accepted at the account level or the **AWS Organizations** level (applies to all member accounts at once).

**Key points:**
- **Free service** — no cost to download reports or accept agreements.
- Reports reflect AWS's own compliance — your workloads still need to be independently compliant. AWS Artifact covers the **infrastructure layer**, not your application.
- Useful for auditors, compliance officers, and legal teams — not a runtime security service.

| | AWS Artifact | AWS Security Hub |
|---|---|---|
| **Purpose** | Download compliance docs and accept agreements | Aggregate security findings across services |
| **Audience** | Auditors, legal, compliance teams | Security operations teams |
| **Output** | PDF reports, certificates, legal agreements | Security findings and compliance scores |
| **Cost** | Free | Paid |
