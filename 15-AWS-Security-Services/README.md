## AWS Security Services
AWS Security Services are designed to help organizations protect their data, applications, and infrastructure in the cloud. These services provide various security features, including threat detection, data protection, identity and access management, and compliance monitoring.

## Key AWS Security Services

| # | Service | Description |
|---|---------|-------------|
| 01 | [ACM (Certificate Manager)](./01-ACM/README.md) | Provision, manage, and auto-renew SSL/TLS certificates |
| 02 | [WAF (Web Application Firewall)](./02-WAF/README.md) | Layer 7 firewall — protect against SQLi, XSS, bots, rate limiting |
| 03 | [Shield](./03-Shield/README.md) | Managed DDoS protection — Standard (free) and Advanced (paid) |
| 04 | [Firewall Manager](./04-Firewall-Manager/README.md) | Centrally enforce WAF, Shield, and security group rules across AWS Organization |
| 05 | [GuardDuty](./05-GuardDuty/README.md) | Intelligent threat detection using ML — monitors CloudTrail, VPC Flow Logs, DNS |
| 06 | [Inspector](./06-Inspector/README.md) | Automated vulnerability scanning for EC2, ECR, and Lambda |
| 07 | [Security Hub](./07-Security-Hub/README.md) | Centralized findings aggregator and compliance dashboard across services and accounts |
| 08 | [Macie](./08-Macie/README.md) | ML-based sensitive data discovery and classification in S3 (PII, credentials, financial data) |
