## AWS Networking Services

| # | Service | Description |
|---|---------|-------------|
| 01 | [VPC](./01-VPC/README.md) | Isolated virtual network — subnets, route tables, IGW, NAT, security groups, NACLs, VPC Peering, Flow Logs |
| 02 | [Route 53](./02-Route-53/README.md) | Scalable DNS — routing policies (Simple, Weighted, Latency, Failover, Geolocation, Geoproximity, Multi-value) |
| 03 | [Direct Connect](./03-Direct-Connect/README.md) | Dedicated private network connection from on-premises to AWS — consistent latency, no internet |
| 04 | [CloudFront](./04-CloudFront/README.md) | Global CDN — edge caching, OAC, signed URLs, Lambda@Edge, WAF integration |
| 05 | [Global Accelerator](./05-Global-Accelerator/README.md) | Anycast static IPs — routes traffic via AWS backbone for improved global performance |
| 06 | [Transit Gateway](./06-Transit-Gateway/README.md) | Regional network hub — connects VPCs and on-premises networks, supports ECMP for VPN scaling |
| 07 | [PrivateLink](./07-PrivateLink/README.md) | Private connectivity to AWS services and your own services without exposing to internet |
| 08 | [AWS VPN](./08-AWS-VPN/README.md) | Site-to-Site VPN (IPsec over internet) and Client VPN for remote user access |
